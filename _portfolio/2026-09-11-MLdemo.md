A machine-learning playground in the spirit of TensorFlow Playground, built to run offline on a
classroom projector. Students watch a model learn, change one thing, and watch again.

![The Circle dataset learned to 100% accuracy, with the network, its loss curve and the decision boundary](/images/mldemo.jpg)
*The Circle dataset learned to 100% accuracy, with the network, its loss curve and the decision boundary.*

### Features

- **Models** — neural networks and k-nearest neighbours, for classification and regression.
- **Datasets** — circle, XOR, Gaussian, spiral and blobs (three to six classes), with noise, train/test split and random-seed controls.
- **Your own data** — click to add points, spray them with a brush, edit them in a table, or import and export CSV.
- **Inside the network** — choose input features, layers and neurons; see each neuron's output and a live loss curve.
- **Extensible** — each new method is one file wrapping a scikit-learn estimator; it registers itself and is checked by the test suite.

Python (Panel, Bokeh, scikit-learn), running as a local web app; 146 automated tests.
