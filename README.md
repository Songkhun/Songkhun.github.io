# songkhun.github.io

Personal academic website of **Songkhun Boonchaisuk** — Geophysicist and Lecturer,
Geoscience Division, Mahidol University, Kanchanaburi Campus, Thailand.

Live at <https://songkhun.github.io>

## What's here

| Path | Contents |
|---|---|
| `_publications/` | Journal articles and conference papers (one file each) |
| `_talks/` | Talks and tutorials |
| `_teaching/` | Course pages |
| `_portfolio/` | Projects, training and certificates |
| `_posts/` | Blog and reading notes |
| `_pages/` | Home, CV, Software, and the collection archives |
| `files/` | PDFs and BibTeX entries linked from publications |

## Running locally

```bash
bundle install
bundle exec jekyll serve --livereload
```

Then open <http://localhost:4000>.
