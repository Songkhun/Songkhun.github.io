Code and teaching material I maintain on [GitHub](https://github.com/Songkhun).
Most are small, practical tools built for teaching or for a specific survey.

## Geophysical processing

**[shp2FracPaQ](https://github.com/Songkhun/shp2FracPaQ)** · Python  
Converts an ESRI shapefile of fracture traces into the tab-delimited coordinate
format required by [FracPaQ](https://fracpaq.com), for quantitative fracture-pattern analysis.

**[Landsat2IronOxide](https://github.com/Songkhun/Landsat2IronOxide)** · Jupyter Notebook  
Band-ratio and principal-component workflow for detecting iron-oxide alteration
in Landsat imagery.

**[Seismic-refraction](https://github.com/Songkhun/Seismic-refraction)** · Jupyter Notebook  
Notebooks for seismic refraction processing and interpretation.

**[ShakeMap](https://github.com/Songkhun/ShakeMap)** · Jupyter Notebook  
Notebook for producing shake maps.

## Teaching and research apps (2026)

Larger tools built in 2026. Each has a page in the [portfolio](/portfolio/); their code is not public yet.

**[openlineament](/portfolio/2026-09-18-openlineament/)** · Python  
Automated lineament extraction from satellite and terrain rasters, tuned and scored against manual mapping.

**[Gravis](/portfolio/2026-09-01-Gravis/)** · Python, SimPEG, pyGIMLi  
Gravity and magnetic forward modelling and inversion on real terrain, for teaching.

**[InversionCoach](/portfolio/2026-10-04-InversionCoach/)** · JavaScript  
Browser lab for 1-D resistivity sounding inversion, equivalence and depth of investigation.

**[MT Viewer](/portfolio/2026-09-23-MTViewer/)** · Python, Blender  
Desktop viewer and Blender add-on for WSINV3DMT and ModEM resistivity models.

**[GroundWater Viewer](/portfolio/2026-09-22-GroundWaterViewer/)** · TypeScript  
Well logs in map, cross-section and 3-D, in one self-contained HTML file.

**[MLdemo](/portfolio/2026-09-11-MLdemo/)** · Python  
Offline machine-learning playground for classroom demonstrations.

**[CourseKit](/portfolio/2026-09-02-CourseKit/)** · Python, Quarto  
Builds slides, handouts, notebooks and problem sets from one source file per topic.

**[kags381-weather-dashboard](https://github.com/Songkhun/kags381-weather-dashboard)** · Python  
Tkinter weather dashboard on the AccuWeather API, teaching material for KAGS381.
